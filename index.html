Anatomía de una Regla CSS

Sintaxis CSS

CSS funciona vinculando reglas de estilo a elementos específicos del DOM HTML. Una regla se compone de un Selector y un Bloque de Declaraciones.

  • ✔ Selector: Apunta al elemento HTML que deseas estilar.
  • ✔ Propiedad: El atributo estético que vas a modificar (ej. color).
  • ✔ Valor: La configuración específica aplicada (ej. red).
  • ✔ Las declaraciones se cierran obligatoriamente con punto y coma (;).
Sintaxis Visual
// Selecciona todos los títulos h1
h1 {
color: #FFC820; // Propiedad y Valor
font-size: 32px;
text-align: center;
}
Dato clave: Los nombres de propiedades CSS distinguen mayúsculas y minúsculas (siempre en minúsculas). Estándares W3C
MÉTODOS

Cómo Incluir CSS en un Proyecto

Buenas Prácticas
En Línea ❌ No recomendado

CSS Inline

Aplicado directamente dentro del atributo style del elemento HTML. 

<p style="color: blue;">
Dificulta el mantenimiento y la reutilización.
Interno ⚠️ Solo pruebas

CSS Interno / Embebido

Declarado dentro de la etiqueta <style> en la sección de la cabecera <head>. 

<style> p { color: blue; } </style>
Útil para páginas únicas o prototipado rápido.
Externo ⭐ Recomendado

Hojas de Estilo Externas

Escrito en un archivo independiente con extensión .css y enlazado mediante la etiqueta HTML <link>. 

<link href="style.css" rel="stylesheet">
Promueve la separación total de estructura y diseño.
Regla de Oro: Separar responsabilidades (HTML para estructura, CSS para presentación, JS para comportamiento). Estándar de la Industria
EJEMPLO 1

Selectores Esenciales (Etiqueta, Clase, ID)

Para aplicar estilos específicos a ciertos elementos de la página de forma selectiva, disponemos de tres selectores clave:

De etiqueta (Type Selector): Selecciona todos los elementos del mismo tipo de etiqueta en la página (ej: h2).
De clase (Class Selector): Selecciona elementos que tengan el atributo class="...". Se define anteponiendo un punto (ej: .card-destacada). Se puede reutilizar en varios elementos.
De identificador (ID Selector): Selecciona un único elemento mediante el atributo id="...". Se define con almohadilla (ej: #menu-principal). Debe ser único en toda la página.

Ejemplo de Renderizado

Este párrafo usa estilo general de etiqueta.

Clase: .destacado

Este párrafo hereda estilos de clase para destacar avisos.

ID: #seccion-unica

Bloque exclusivo estilado mediante identificador ID único.

<!-- Estructura HTML -->
<p>Estilo general de etiqueta.</p>
<div class="destacado">Estilos de clase.</div>
<div id="seccion-unica">Estilos de ID.</div>

/* Hoja de Estilos CSS */
p {
  color: #374151;
  font-style: italic;
}

.destacado {
  background-color: #FEF08A;
  border: 1px solid #FACC15;
  padding: 12px;
}

#seccion-unica {
  background-color: #111827;
  color: #FFFFFF;
  padding: 12px;
}
EJEMPLO 2

El Modelo de Caja (Box Model)

En CSS, cada elemento HTML es representado de forma abstracta como una caja rectangular compuesta de capas concéntricas:

Margin: El espacio vacío ubicado fuera del borde, aislando la caja de otros elementos.
Border: La línea física perimetral que encierra el relleno y el contenido del elemento.
Padding: El espacio interno de separación entre el borde y el contenido del elemento.
Content: El núcleo del elemento donde se renderiza el texto o las imágenes.

EJEMPLO 3

Estilando Texto y Fondos

La personalización de fuentes, alineaciones y contrastes representa una de las tareas principales al maquetar con hojas de estilo:

  • font-family: Configura la tipografía de lectura del elemento. Se recomiendan fuentes sin serifa (sans-serif) para mejorar la visualización en pantallas digitales.
  • color & background-color: Define el contraste de color del texto principal y el fondo de la caja, utilizando formatos hexadecimales (#111827) o nombres de color estandarizados.

EJEMPLO 4

Efectos Interactivos con Hover

Las pseudoclases permiten estilar un elemento HTML dependiendo del estado de interacción en el que se encuentre.

:hover: Se activa de inmediato cuando el usuario posiciona el cursor del mouse encima del elemento objetivo.
transition: Permite que los cambios de color, tamaño o borde ocurran de manera gradual y suave, en lugar de aplicarse instantáneamente.
Vista Previa Interactiva

Pasa el cursor del mouse sobre los botones:

/* Botón con transición suave */
.btn-accion {
  background-color: #111827;
  color: #FFC820;
  border-radius: 12px;
  padding: 10px 24px;
  
  /* Transición suave de 0.3s */
  transition: all 0.3s ease;
}

/* Efecto dinámico al pasar el cursor */
.btn-accion:hover {
  background-color: #FFC820;
  color: #111827;
}
